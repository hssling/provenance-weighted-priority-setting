# Provenance-weighted priority setting

Instrument for scoring indicator provenance, propagating it into priority rankings, and valuing its resolution.

Spec: `../docs/superpowers/specs/2026-11-13-provenance-weighted-priority-setting-design.md`

The repository holds the code, the public input data, the time-stamped analysis plan (`docs/`) and the verification suite. Manuscript texts are not distributed here; checks that compare numbers with a manuscript report SKIPPED or fail when the manuscript file is absent.
